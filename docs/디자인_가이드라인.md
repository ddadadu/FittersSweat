# FittersSweat 디자인 가이드라인 (Design Guidelines)

> **버전**: 1.0.0  
> **기준 레퍼런스**: [Supahero.io](https://supahero.io/) Dark Athletic Showcase 패턴  
> **핵심 철학**: `ui-ux-pro-max` (디자인 인텔리전스 & 정밀성) + `ponytail` (불필요한 코드 없는 하이브리드 미니멀 모션)  
> **모션 구현 전략**: **하이브리드 방식** (기본 인터랙션: Tailwind CSS 0kb + 퇴장/리스트 재배치: Framer Motion 선별 적용)

---

## 1. 디자인 철학 및 시스템 개요

FittersSweat은 고강도 하이브리드 피트니스 레이스인 **HYROX**에 특화된 커머스 및 커뮤니티 플랫폼입니다.  
본 디자인 가이드라인은 단순한 시각적 미려함을 넘어, **"사용자가 레이스 장비를 탐색하고, 구매 결정을 내리고, 커뮤니티에서 훈련 노하우를 습득하는 모든 여정에서 인지 부하를 최소화하고 신뢰감을 부여하는 것"**을 절대적 목표로 삼습니다.

### 3대 핵심 원칙
1. **High-Contrast Athleticism**: 어둡고 묵직한 다크 톤(`#0A0A0A`)을 베이스로 하여 고해상도 장비 이미지와 HYROX Official Gold(`#FFD700`) 포인트 컬러가 강렬하게 부각되도록 설계.
2. **Spatial Continuity (공간적 연속성)**: 화면 이동이나 필터 조작 시 화면이 깜빡이지 않고, 요소의 이동과 상태 변화가 사용자 눈에 부드럽게 추적되도록 보장.
3. **Purposeful Motion (목적 지향적 모션)**: 장식만을 위한 무의미한 애니메이션을 철저히 배제하고, 사용자에게 **행동 확신(Feedback)**, **시선 유도(Focus)**, **인지 과부하 방지(Clarity)**를 제공하는 모션만 선별 탑재.

## 2. "이 Motion이 사용자에게 어떤 도움을 주는가?" (Motion UX Rationale)

`supahero.io`의 핵심 인터랙션 패턴을 분석하여 도출한 6대 모션의 기능적 UX 가치입니다.

| 모션 패턴 | 구현 기술 | 시각적 동작 | 사용자가 얻는 기능적 UX 도움 (Why it matters) |
| :--- | :--- | :--- | :--- |
| **1. 카드 호버 스케일업 & 테두리 점등** | Tailwind CSS<br>`group-hover:scale-[1.02]`<br>`group-hover:border-[#FFD700]/60`<br>(200ms ease-out) | 마우스 오버 시 카드가 미세하게 2% 확대되며 테두리에 골드빛 하이라이트 점등 | **선택 확신 부여 및 오클릭 방지**<br>400개의 방대한 장비 카탈로그를 빠르게 스크롤할 때, 마우스 포인터가 정확히 어느 카드를 가리키고 있는지 공간적으로 명확히 분리해 주어 잘못된 클릭을 사전에 방지합니다. |
| **2. 그라디언트 딤 + 텍스트 슬라이드업** | Tailwind CSS<br>`group-hover:opacity-40`<br>`translate-y-2 -> 0`<br>(250ms ease-out) | 평소에는 장비 비주얼만 보이다가 호버 시 어두운 그라디언트와 함께 세부 스펙/태그 노출 | **시각적 인지 과부하(Cognitive Overload) 방지**<br>모든 정보(가격, 스테이션, 재고, 무게 등)를 상시 노출하면 시각적 피로도가 급증합니다. 평소에는 장비 실물에 시선을 집중시키고, 관심을 보일 때만 2차 정보를 노출합니다. |
| **3. 장바구니 뱃지 펄스 (Micro-feedback)** | Tailwind CSS<br>`animate-pulse` or<br>`scale-125 -> scale-100`<br>(150ms spring) | [장바구니 담기] 클릭 시 상단 네비바의 카트 카운트 숫자가 일시적으로 튀어오름 | **비동기 작업 완료의 즉각적 확신**<br>화면을 이동하지 않는 비동기 카트 추가 시, "정말 담겼나?"라는 불안감으로 중복 클릭하는 문제를 방지하고 구매 진행 상황을 즉각 전달합니다. |
| **4. 퇴장 애니메이션 (Exit Transition)** | Framer Motion<br>`<AnimatePresence>`<br>`exit={{ opacity: 0, scale: 0.95 }}` | 장바구니 아이템 삭제 또는 모달 닫기 시 부드럽게 축소되며 페이드아웃 | **인지적 단절(Cognitive Jolt) 방지**<br>React에서 컴포넌트가 DOM에서 즉시 증발하면 사용자는 삭제가 정상 처리되었는지, 에러로 튕긴 것인지 혼란을 겪습니다. 부드러운 퇴장으로 안심감을 제공합니다. |
| **5. 동적 리스트 재배치 (FLIP Layout)** | Framer Motion<br>`layout` prop<br>(spring physics) | 카테고리/스테이션 필터 변경 시 사라지는 카드를 제외한 나머지 카드가 부드럽게 빈자리로 이동 | **시각적 연속성 (Spatial Continuity)**<br>필터 클릭 시 화면 전체가 깜빡이며 재렌더링되는 대신, 기존 아이템들이 유기적으로 재배치되어 "어떤 장비가 필터링되었고 무엇이 남았는지" 시선이 흐름을 잃지 않습니다. |
| **6. 스티키 블러 헤더** | Tailwind CSS<br>`sticky top-0 z-50`<br>`backdrop-blur-md bg-black/80` | 스크롤 시 뒤쪽 콘텐츠가 은은하게 비치며 상단에 고정 유지 | **탐색 자유도 보장 및 원클릭 복귀**<br>긴 스크롤(400개 카탈로그, 긴 완주 후기) 중에도 언제든 장바구니, 대회 일정, 마이페이지로 즉시 복귀할 수 있어 이탈률을 낮춥니다. |

## 3. 디자인 토큰 시스템 (Design Tokens)

### 3.1 컬러 팔레트 (Color System)
명도 대비 4.5:1(WCAG AA 기준)을 엄격히 준수합니다.

```css
/* Backgrounds */
--bg-canvas: #0A0A0A;       /* 최하단 메인 캔버스 */
--bg-surface: #141414;      /* 기본 카드 및 모달 배경 */
--bg-elevated: #1F1F1F;     /* 호버 시 또는 인셋 컨테이너 배경 */
--bg-subtle: #262626;       /* 보조 인풋 및 칩 배경 */

/* Borders */
--border-subtle: #262626;   /* 기본 구분선 */
--border-default: #333333;  /* 컴포넌트 기본 외곽선 */
--border-focus: #FFD700;    /* 포커스 및 액티브 강조선 */

/* Brand & Accents */
--brand-gold: #FFD700;      /* HYROX 공식 골드 (Primary CTA, 배지) */
--brand-gold-hover: #E6C200;
--brand-lime: #CCFF00;      /* 활력/에너지 포인트 (스테이션 하이라이트) */
--brand-danger: #EF4444;    /* 품절, 삭제, 오류 경고 */
--brand-success: #10B981;   /* 결제 완료, 정품 인증 */

/* Text & Foreground */
--text-primary: #F5F5F5;    /* 96% 화이트 - 헤드라인 및 주요 본문 */
--text-secondary: #A3A3A3;  /* 64% 그레이 - 서브 타이틀 및 레이블 */
--text-muted: #737373;      /* 45% 그레이 - 비활성 및 캡션 */
```

### 3.2 타이포그래피 스케일 (Typography)
폰트: `Inter`, `-apple-system`, `BlinkMacSystemFont`, `Pretendard`, sans-serif

| 구분 | Tailwind Class | Size / Line-height | Weight | 용도 |
| :--- | :--- | :--- | :--- | :--- |
| **Display** | `text-4xl md:text-5xl` | 36px / 44px ~ 48px / 56px | 900 (Black) | Hero 헤드라인, 브랜드 슬로건 |
| **Heading 1**| `text-2xl md:text-3xl` | 24px / 32px ~ 30px / 38px | 800 (ExtraBold)| 페이지 메인 타이틀, 대회 명칭 |
| **Heading 2**| `text-xl md:text-2xl` | 20px / 28px ~ 24px / 32px | 700 (Bold) | 섹션 헤더, 모달 타이틀 |
| **Heading 3**| `text-lg` | 18px / 26px | 600 (SemiBold)| 상품명, 게시글 제목, 카드 헤더 |
| **Body Large**| `text-base` | 16px / 24px | 500 (Medium) | 장바구니 상품명, 주요 강조 본문 |
| **Body Regular**| `text-sm` | 14px / 20px | 400 (Regular) | 카탈로그 스펙 설명, 리뷰 본문 |
| **Caption** | `text-xs` | 12px / 16px | 500 (Medium) | 날짜, 스테이션 칩 배지, 가격 보조문구 |

### 3.3 곡률 및 간격 시스템 (Radius & Spacing)
- **Rounded**:
  - Small (`rounded-md` / 6px): 인풋 박스, 콤팩트 태그
  - Medium (`rounded-xl` / 12px): 상품 카드, 모달 윈도우, 테이블 박스
  - Pill (`rounded-full` / 9999px): 필터 탭 칩, 상태 배지, 원형 아이콘 버튼
- **Touch Target**: 모든 클릭 가능 요소는 최소 `44px x 44px` 이상의 히트 영역 확보 (`min-h-[44px] min-w-[44px]`).

## 4. 컴포넌트 규격 및 인터랙션 정의 (Component Specifications)

### 4.1 글로벌 네비게이션 바 (Global Sticky Navbar)
- **높이**: `h-16` (64px 고정)
- **배경**: `bg-[#0A0A0A]/85 backdrop-blur-md border-b border-[#262626]`
- **구성 요소**:
  - 좌측: `FITTERSWEAT` 로고 (볼드 타이포 + 골드 번개 아이콘)
  - 중앙: 4대 메인 네비게이션 링크 (`대회 일정`, `레이서 장비몰`, `커뮤니티`, `마이페이지`)
    - 활성 상태(Active): 텍스트 `#FFD700` + 하단 2px 골드 언더라인 바
    - 기본 상태: 텍스트 `#A3A3A3`, 호버 시 `#FFFFFF`
  - 우측: 장바구니 아이콘 (Lucide `ShoppingBag` SVG) + 수량 배지(`bg-[#FFD700] text-black font-black text-xs px-1.5 py-0.5 rounded-full`)

### 4.2 Hero 쇼케이스 배너 (`supahero.io` 스타일)
- **규격**: 높이 `min-h-[420px] md:min-h-[500px]`, 전체 폭 반응형 컨테이너
- **비주얼**: 다크 앰비언트 그라디언트 + 고강도 HYROX 레이스 경기장 배경 텍스처
- **카피라이팅 위계**:
  1. Eyebrow Tag: `OFFICIAL HYROX RACER COLLECTION` (골드 텍스트, 12px, 자간 추적 `tracking-widest`)
  2. Headline: `LIMITLESS ENDURANCE, PROVEN GEAR.` (대담한 48px 볼드 타이포)
  3. Description: `실제 완주 레이서들이 검증한 400여 종의 경기 전용 슈즈, 영양, 장비 라인업`
  4. Dual Action CTA:
     - Primary: `[장비 카탈로그 탐색하기]` (`bg-[#FFD700] text-black hover:bg-[#E6C200] font-bold px-6 py-3 rounded-xl`)
     - Secondary: `[대회 후기 & 훈련팁]` (`bg-white/10 hover:bg-white/20 text-white border border-white/20 px-6 py-3 rounded-xl`)

### 4.3 상품 카드 (Product Card)
400개 카탈로그 리스트의 핵심 단위 블록입니다.
- **컨테이너**: `bg-[#141414] border border-[#262626] rounded-xl overflow-hidden group cursor-pointer transition-all duration-200 hover:border-[#FFD700]/50 hover:shadow-xl hover:shadow-[#FFD700]/5`
- **상단 비주얼 영역**:
  - 비율: `aspect-square` (1:1 정사각 고정, 레이아웃 쉬프트 방지)
  - 이미지: Cloudinary CDN 최적화 이미지 (`object-cover w-full h-full transition-transform duration-300 group-hover:scale-105`)
  - 좌상단 배지: 카테고리 칩 (`SHOES`, `NUTRITION`, `GEAR`, `EQUIPMENT`)
  - 우상단 배지: 남은 재고(`품절 임박: 3개 남음` 등 긴급도 피드백)
- **하단 정보 영역**:
  - 제조사/브랜드 (`text-xs text-[#737373] uppercase`)
  - 상품명 (`text-sm font-semibold text-white line-clamp-1 group-hover:text-[#FFD700] transition-colors`)
  - 가격 (`text-base font-extrabold text-white`)
  - 하단 액션: 카드 호버 시 부드럽게 노출되는 [장바구니 담기] 퀵 버튼

### 4.4 카테고리 & 스테이션 필터 바 (Filter Bar)
- **형태**: 모바일 횡스크롤 지원 알약(Pill) 칩 리스트
- **칩 규격**: `h-10 px-4 rounded-full text-sm font-semibold transition-colors`
  - 선택됨: `bg-[#FFD700] text-black shadow-md shadow-[#FFD700]/20`
  - 미선택: `bg-[#1F1F1F] text-[#A3A3A3] hover:text-white hover:bg-[#262626]`
- **검색 및 정렬**: 우측에 디바운스 실시간 검색 인풋과 정렬 드롭다운(`최신순`, `낮은가격순`, `높은가격순`) 배치

### 4.5 장바구니 드로어 & 주문 요약 카드 (Cart Summary)
- **품목 리스트**:
  - 1:1 썸네일(64x64px), 상품명, 단가, 수량 증감 버튼(`-`, `+`), 삭제 아이콘 버튼
  - **Framer Motion 적용**: 품목 삭제 시 `<motion.div exit={{ opacity: 0, x: -20 }} layout>` 적용
- **주문 금액 요약**:
  - 총 상품 금액 + 배송비(0원 프로모션) = 최종 결제 금액(`text-2xl font-black text-[#FFD700]`)
  - 무료배송 진행률 게이지 바(100% 달성 축하 메시지)
  - 결제 CTA 버튼: `[Toss Payments 결제하기]` (풀 위드, 52px 높이)

### 4.6 커뮤니티 포스트 카드 (Post Card)
- **컨테이너**: `bg-[#141414] border border-[#262626] rounded-xl p-5 hover:border-white/30 transition-all`
- **헤더**: 작성자 프로필(HYROX 완주 횟수 배지), 작성일, 대회 태그 (`#2026_HYROX_SEOUL`)
- **본문 요약**: 제목(`text-base font-bold text-white`), 본문 2줄 말줄임(`line-clamp-2 text-sm text-[#A3A3A3]`)
- **태그된 장비 칩**: 본문에서 언급된 실제 직매입 장비 썸네일과 이름 태그 (`bg-[#1F1F1F] border border-[#333333] rounded-lg px-2.5 py-1 text-xs text-white hover:border-[#FFD700]`)
- **푸터**: 댓글 수, 조회수

## 5. 시각적 결함 및 사용성 검토 체크리스트 (Visual Defect Checklist)

구현 단계 및 PR 머지 전 아래 8대 항목을 필수로 검증합니다.

| 검증 항목 | 검토 기준 | 결함 판정 조건 (FAIL) | 방지책 및 해결 가이드 |
| :--- | :--- | :--- | :--- |
| **1. 텍스트 명도 대비** | WCAG AA 기준 4.5:1 이상 | 텍스트 컬러가 `#737373` 이하이면서 본문/가격에 사용된 경우 | 주요 정보는 반드시 `#F5F5F5` 또는 `#FFD700` 사용 |
| **2. 누적 레이아웃 이동 (CLS)** | 이미지 로드 시 주변 요소 밀림 0 | 이미지 컨테이너의 너비/높이가 고정되지 않아 렌더링 시 깜빡임 발생 | `aspect-square`, `w-full h-full object-cover`, 스켈레톤 UI 사전 렌더링 |
| **3. 터치 타겟 최소 크기** | 최소 44x44px 영역 보장 | 모바일에서 수량 변경 `+`, `-` 버튼이나 삭제 아이콘의 클릭 반경이 36px 미만인 경우 | 버튼에 `p-2.5` 또는 `min-h-[44px] min-w-[44px]` 유틸리티 적용 |
| **4. 텍스트 오버플로우 (말줄임)** | 긴 상품명/작성자명 레이아웃 파괴 방지 | 글자 수가 길어질 때 카드가 아래로 늘어나거나 버튼을 침범하는 경우 | `truncate` 또는 `line-clamp-1`, `line-clamp-2` 적용 |
| **5. 포커스 링 가시성** | 키보드 접근성 (Tab 키 탐색) | 포커스 시 아무런 시각적 표시가 없거나 아웃라인이 완전히 지워진 경우 | `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-[#FFD700]` 명시 |
| **6. 모달 백드롭 스크롤 잠금** | 모달 열림 시 배경 스크롤 차단 | 모달이 뜬 상태에서 배경 페이지가 함께 스크롤되는 경우 | 모달 마운트 시 `document.body.style.overflow = 'hidden'` 적용 |
| **7. 모바일 세이프 에어리어** | iOS 하단 홈 인디케이터 간섭 방지 | 모바일 최하단 고정 CTA 버튼이 홈 바에 가려져 클릭이 방해받는 경우 | `pb-[env(safe-area-inset-bottom)]` 또는 `pb-6` 안전 여백 추가 |
| **8. 아이콘 표준화** | 일관된 비주얼 톤 유지 | 이모지(👟, 🛒)가 시스템 UI에 혼용되거나 해상도가 깨지는 경우 | 예외 없이 `lucide-react` SVG 벡터 아이콘으로 100% 통일 |

## 6. 하이브리드 모션 구현 규칙 (Implementation Rules)

1. **기본 원칙**:
   - 컴포넌트의 90%에 달하는 마우스 오버, 색상 변화, 보더 점등은 오직 **Tailwind CSS 유틸리티**(`transition-all duration-200 ease-out`)만을 사용합니다.
   - 불필요하게 `motion.div`를 남발하지 않고, 순수 DOM 렌더링 성능을 최우선합니다.
2. **Framer Motion 선별 적용 규칙**:
   - 오직 **조건부 렌더링으로 사라지는 컴포넌트(`AnimatePresence`)**와 **순서가 재배열되는 리스트(`layout`)**에만 제한적으로 사용합니다.
   - Next.js Server Component 구조를 유지하기 위해, Framer Motion이 필요한 부분은 `components/motion/MotionDrawer.tsx` 또는 `components/motion/MotionListItem.tsx`와 같이 최소 단위의 Client Component 래퍼로 캡슐화합니다.
